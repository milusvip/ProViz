使用说明

  1. 选择模型 → 自动填入 API 地址 → 填入你的 API Key → 保存
  2. 在任意网页 右键 图片 → 「反推此图片的提示词」
  3. 或在任意网页 右键 → 「截图反推提示词」→ 拖选区域 → 确认
  4. 在确认浮窗中选择语言，点击「开始反推」
  5. 结果会自动保存在弹窗历史中
